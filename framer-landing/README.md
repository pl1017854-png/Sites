# 🌙 LUNARIS Landing Page — Framer Motion Edition

Uma landing page premium para a Luminária Lua 3D com animações sofisticadas usando **Framer Motion**, **React** e **Tailwind CSS**.

## 🚀 Tech Stack

- **React 18** — Biblioteca UI moderna
- **Vite** — Build tool ultrarrápido
- **Framer Motion** — Animações declarativas e fluidas
- **Tailwind CSS** — Styling utility-first
- **JavaScript ES6+**

## ⚡ Features

✨ **Animações Framer Motion:**
- Hero com stagger animations e reveal ao carregar
- Cards com whileHover e spring transitions
- Seções com whileInView (reveal ao scroll)
- Countdown com updateAnimation contínua
- Progress bar sincronizada com scroll
- Layout animations e saídas suaves

🎨 **Design Premium:**
- Glassmorphism com backdrop-filter blur
- Gradientes elegantes em degradê
- Sombras sofisticadas
- Paleta ouro + preto + vermelho
- Totalmente responsivo

📱 **Responsive:**
- Mobile-first
- Breakpoints: sm, md, lg
- Zero overflow horizontal

## 🛠️ Instalação

\`\`\`bash
cd framer-landing
npm install
npm run dev
\`\`\`

Abre em **http://localhost:5173/**

## 📦 Build

\`\`\`bash
npm run build
npm run preview  # serve a build
\`\`\`
